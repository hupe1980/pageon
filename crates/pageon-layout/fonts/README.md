# Bundled fonts

Liberation Fonts 2.1.5 (https://github.com/liberationfonts/liberation-fonts), SIL Open Font
License 1.1 (see `LICENSE`). Metric-compatible with Arial, Times New Roman and Courier New, so
layout is identical on every machine and close to Chromium.

`moz-bullet-font.otf`: the list-marker font (family `Bullet`) from Blitz (blitz-dom
0.3.0-beta.4 `assets/moz-bullet-font.otf`, MIT OR Apache-2.0), derived from Mozilla's bullet
font (Mozilla Public License 2.0, https://mozilla.org/MPL/2.0/).
